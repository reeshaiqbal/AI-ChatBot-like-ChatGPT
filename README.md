# AI-ChatBot-like-chatgpt

This AI Chat Bot perform like Chatgpt.
Requirements:

1. pip install openai
2. pip install gradio

How to add your API key in the code ?
Need to grab openai API key by this link:
https://platform.openai.com/account/api-keys
Click on create new key, copy it and paste it in the code where strings of variable is Open_AI_Key.
